## Architecture (current)

```
Question or microbiome profile (CSV)
  -> query (profiles are converted to a question: community state, taxa, diversity)
  -> embed (all-MiniLM-L6-v2) -> ChromaDB similarity search, top 15
  -> Safety gate 1: best-match distance > 0.9 ?  -> decline, no LLM call
  -> cross-encoder re-ranking (ms-marco-MiniLM-L-6-v2): 15 candidates -> best 5
  -> grounded prompt -> Gemini (citations required; "no evidence" vs "uncertain evidence" are distinguished)
  -> Safety gate 2 (in the prompt): INSUFFICIENT_EVIDENCE when the sources do not address the question
  -> cited answer with PMIDs
```

Answers are generated by `gemini-flash-lite-latest` (the model used in the evaluation), with an automatic fallback to
`gemini-flash-latest` if the first model's free daily quota is exhausted. Transient API errors are retried with backoff.

## Evaluation

`eval_ablation.py` runs 42 queries through three configurations and grades every answer with an LLM judge that is a
**different model from the generator** (GPT-OSS-120B via Groq; the answers come from Gemini).

- 36 in-scope questions: symptoms, risk factors, diagnosis, treatment, mechanism, two mixed-evidence questions and
  four profile-style queries.
- 6 questions that should be declined: 4 off-topic and 2 gynaecological near-misses (endometriosis, PCOS).
- Configurations: **baseline** (top-5, gate on), **rerank** (top-15 re-ranked to 5, gate on), **no_gate** (gate off).

Results (single run, `eval_results.csv`; metrics averaged over answered queries):

| In-scope questions (n = 36) | Baseline | With re-ranking |
|---|---|---|
| Answered / declined | 27 / 9 | 28 / 8 |
| Faithfulness | 0.972 | 0.916 |
| Answer relevance | 0.908 | 0.891 |
| Context precision | 0.622 | 0.593 |

| Should-decline queries (n = 6) | Correctly declined |
|---|---|
| Distance gate + prompt guard | 6 / 6 |
| Prompt guard only (gate off) | 5 / 6 |

Best-match distance (gate threshold 0.9): in-scope 0.40-0.88 (one outlier at 1.33), near-miss 1.01-1.22, off-topic 1.40-1.59.

**Findings**

- Re-ranking produced **no detectable improvement**: on the 26 queries answered in both configurations the 95% bootstrap
  intervals for the change in context precision (-0.115 to +0.092), faithfulness and answer relevance all include zero.
  Repeating the evaluation changed the same metrics by up to about 0.05, so differences of that size are noise.
- The distance gate declined all 6 out-of-scope queries. With the gate off, "symptoms of endometriosis" was answered from one
  loosely related abstract; the judge rated it faithful, so faithfulness alone cannot detect a scope violation.
- 9 of 36 in-scope questions were declined (1 by the gate, 8 by the model's own rule), concentrated in risk-factor,
  diagnosis, mechanism and profile queries.

**Limitations:** 42 queries and one reported run; non-deterministic generation; the judge is an LLM and was not
validated against human ratings in this version; hand-written queries not checked against the corpus; 350 abstracts only
(no full texts); one condition (BV); synthetic profiles; context precision is not rank-aware. This is a research
prototype, not a diagnostic tool.
